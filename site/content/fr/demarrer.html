Installer et démarrer

Un seul binaire, qui embarque l'interface. Seul Claude Code doit déjà être installé : Glaude Code (la commande gld) lit le dossier ~/.claude et n'envoie rien ailleurs.

Installer le binaire de la release

Choisissez le fichier de votre système sur la dernière release : gld-linux-amd64, gld-linux-arm64, gld-darwin-arm64, gld-darwin-amd64, gld-windows-amd64.exe… La liste complète et le fichier SHA256SUMS sont sur la page. Ni Go, ni Node.js, ni make ne sont nécessaires.

Exemple pour Linux amd64, avec vérification de l'origine et de l'empreinte :

curl -LO https://github.com/54tor/glaude-code/releases/latest/download/gld-linux-amd64
curl -LO https://github.com/54tor/glaude-code/releases/latest/download/SHA256SUMS
gh attestation verify gld-linux-amd64 --repo 54tor/glaude-code
sha256sum --ignore-missing -c SHA256SUMS
chmod +x gld-linux-amd64 && mv gld-linux-amd64 ~/.local/bin/gld
gld --version

Le dossier ~/.local/bin doit être dans votre PATH.

Compiler depuis les sources

Il faut Go 1.25 ou plus récent, Node.js et Claude Code déjà installé.

git clone https://github.com/54tor/glaude-code
cd glaude-code
make install

La commande gld est installée dans ~/.local/bin.

Lancer

gld

Ouvrez ensuite http://127.0.0.1:8799 dans votre navigateur. C'est tout : par défaut, la page n'est visible que depuis votre ordinateur.

Pour l'ouvrir depuis un téléphone ou un autre poste, voir Téléphone et accès distant.

Port déjà pris

Si le port 8799 est occupé, choisissez-en un autre :

GLD_WEB_PORT=8800 gld

Choisir la langue

Glaude Code parle français et anglais. La langue vient du réglage language de ~/.claude/settings.json, le même que celui de Claude Code ; vous le modifiez dans la page Configuration.

  • French ou fr donne le français, English ou en l'anglais.
  • Toute autre langue donne l'interface en anglais ; les titres automatiques, explications et rédactions demandés à Claude suivent votre réglage.
  • Sans réglage, l'interface suit la langue du navigateur, les commandes gld-* suivent LC_ALL puis LANG, et le serveur parle français.
  • Le contenu de vos sessions, mémoires, skills et snippets n'est jamais traduit.

Windows

Le support Windows est compilé mais pas encore testé sur une vraie machine. Sans tmux, gld.exe ne peut pas écrire dans une session déjà ouverte (seule la reprise avec un message marche) et les équipes d'agents sont refusées. WSL2 est la voie recommandée.

Avec WSL2 (recommandé)

Sous WSL2, la version Linux fonctionne telle quelle, tmux compris. Tout s'installe dans la distribution Linux, pas côté Windows.

  1. Dans PowerShell : wsl --install, puis redémarrez.
  2. Dans WSL, installez Claude Code (l'installeur natif ne demande ni Node.js ni Python) et tmux : sudo apt install tmux.
  3. Installez le binaire gld-linux-amd64 comme ci-dessus et vérifiez que ~/.local/bin est dans le PATH.
  4. Lancez gld dans WSL, puis ouvrez http://127.0.0.1:8799 dans le navigateur Windows (WSL2 redirige localhost).

Points d'attention :

  • gld lit le ~/.claude de la distribution. Les sessions créées côté Windows (C:\Users\<vous>\.claude) n'y sont pas : copiez le dossier, ou lancez CLAUDE_CONFIG_DIR=/mnt/c/Users/<vous>/.claude gld (accès plus lent).
  • « Envoyer à la session » exige que la session tourne dans un tmux de WSL ; celles lancées depuis l'interface web s'y ouvrent déjà.
  • Si localhost ne répond pas, changez de port (GLD_WEB_PORT=8800 gld) ou activez networkingMode=mirrored dans .wslconfig.
