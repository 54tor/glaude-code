Questions fréquentes

Données, sécurité, sauvegardes, coûts : les réponses courtes, avec le renvoi vers la page qui détaille.

Mes conversations partent-elles quelque part ?

Non. Glaude Code lit les fichiers locaux de Claude Code (~/.claude). Seules les actions qui font appel à Claude (écrire à une session, réécrire une entrée de mémoire, compter des tokens) passent par votre propre Claude Code. Aucun compte claude.ai n'est requis et rien ne transite par un tiers.

Puis-je casser ma configuration ?

Chaque écriture est précédée d'une sauvegarde et d'un aperçu des changements. Les fichiers de mémoire et de règles supprimés vont à la corbeille, d'où ils se restaurent en un clic. Voir Skills, snippets et réglages et Mémoire et règles.

Le port 8799 est déjà pris.

Lancez GLD_WEB_PORT=8800 gld.

Combien coûte un message envoyé depuis la page ?

Chaque message recharge tout le contexte : environ 1 à 2 $ sur une session froide, bien moins sur une session au cache encore chaud (active depuis moins d'une heure). Glaude Code annonce le coût d'un envoi sur session froide, et la vue En cours et cache chaud liste les sessions les moins chères à reprendre. Voir Sessions.

Ça marche sous Windows ?

Oui via WSL2, qui est la voie recommandée. Le binaire natif Windows est compilé mais n'a pas encore été testé sur une vraie machine. Voir Installer et démarrer.

Comment l'ouvrir depuis mon téléphone ?

Lancez gld --listen 0.0.0.0, ouvrez l'adresse affichée, puis jumelez le téléphone avec un code à huit chiffres. Les notifications exigent HTTPS. Ne l'exposez jamais directement sur Internet. Voir Téléphone et accès distant.

Un invité peut-il voir mes autres sessions ou mes fichiers ?

Non : il ne voit que la session partagée, sans pouvoir répondre aux permissions ni lire les fichiers de configuration, et les chemins absolus, le nom de votre compte et votre identité git y sont masqués. Mais une session sans demande de permission exécute ses messages directement : ne la partagez qu'avec quelqu'un de confiance. Voir Partager une session.

J'ai redémarré ma machine, où sont mes sessions ?

Glaude Code note les sessions ouvertes toutes les 2 minutes : cliquez sur Tout rouvrir, ou lancez gld matin --resume. Voir Sessions.

Plusieurs personnes peuvent-elles l'utiliser ?

Oui, en mode multi-utilisateur : un compte par personne, un second facteur obligatoire et neuf droits indépendants par dossier de configuration. Les droits exec et config_write équivalent au compte système qui fait tourner gld.

Comment changer la langue ?

Via le réglage language de ~/.claude/settings.json, modifiable dans la page Configuration. Voir Installer et démarrer.
