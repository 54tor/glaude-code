Sessions

Retrouver « la session d'hier », la relire, la reprendre ou lui écrire sans ouvrir de terminal, et ne rien perdre quand la machine redémarre.

Retrouver une session

  • La page d'accueil montre vos sessions des 7 derniers jours, rangées par projet. Un point vert signale celles qui sont ouvertes en ce moment.
  • La recherche (touche /) fouille les titres et le texte des conversations.
  • La vue En cours et cache chaud montre les sessions actives depuis moins d'une heure : les reprendre maintenant coûte moins cher, car le cache de contexte de Claude est encore chaud.
  • Chaque session indique sa taille en tokens ; le dossier du projet est affiché sous le titre.

Relire et reprendre

  1. Cliquez sur une session pour la relire en entier. Les appels d'outils sont repliés pour garder la conversation lisible.
  2. Cliquez sur Reprendre pour la rouvrir dans un terminal, avec un message de départ si vous le souhaitez.
  3. Pour agir sur une ou plusieurs sessions : clic droit, ou Maj+clic pour en sélectionner une série. Vous pouvez renommer, exporter en Markdown, déplacer (vers un autre dossier de projet) ou supprimer.

Une session supprimée n'est pas perdue de vue : elle passe par une corbeille.

La vue d'un projet

Cliquer sur un dossier de la barre latérale ouvre la vue du projet : toutes ses sessions, rangées par date, et de quoi le piloter.

  • État git : branche, fichiers modifiés et non suivis, commits en avance, et un bouton Pousser.
  • Bloc-notes : une liste de tâches à cocher propre au projet. Chaque note peut devenir une nouvelle session (Nouvelle session avec la note) ou être envoyée à une session déjà ouverte (Envoyer à une session ouverte).
  • Mémoire du projet : nombre de fichiers et tokens chargés à chaque session (voir Mémoire et règles).
  • Permissions du projet et Espace de travail en un clic ; Reprendre les récentes rouvre les dernières sessions du dossier.

Écrire à une session sans terminal

Depuis le lecteur, tapez un message : Claude répond dans la page. Si la session tourne déjà dans un terminal tmux, le bouton Envoyer à la session écrit directement dedans, et vous voyez en direct ce que Claude fait.

Coût. Chaque message envoyé ainsi recharge tout le contexte : comptez environ 1 à 2 $ par message sur une session froide. La vue « cache chaud » sert précisément à repérer les sessions bon marché à relancer, et Glaude Code annonce le coût d'un envoi sur session froide.

Envoyer pendant que Claude travaille

Un message part tout de suite, même pendant que Claude travaille. Le menu du bouton d'envoi propose :

  • Envoyer en interrompant : la réponse en cours s'arrête, le message passe.
  • Attendre le repos (case mémorisée par session) : le message n'est envoyé qu'au moment où Claude attend.

Une question en attente (Claude vous demande un choix ou une autorisation) met toujours le message en file : il part quand la question est traitée. Le bouton Arrière-plan envoie Ctrl+B à la session tmux pour passer la tâche en cours en arrière-plan.

Démarrer une nouvelle session

Le bouton Nouvelle session (premier de la barre de navigation) demande le message de départ et le dossier : l'explorateur propose d'abord vos projets récents. Pour limiter les dossiers parcourables, voir Restreindre l'explorateur de dossiers.

Ne rien perdre au redémarrage

Glaude Code note toutes les 2 minutes les sessions ouvertes. Après un redémarrage de la machine, Tout rouvrir les relance, chacune dans son onglet. En ligne de commande :

gld matin             # rouvre les sessions d'un projet
gld matin --resume    # rouvre la dernière sauvegarde

Plusieurs dossiers de configuration

Si vous avez plusieurs dossiers de configuration Claude (par exemple un pour le travail, un pour le personnel), le sélecteur en haut de la barre latérale permet d'en ajouter, d'en retirer de la liste et de passer de l'un à l'autre. Chaque dossier a ses sessions, sa mémoire et ses réglages.

Revues de sécurité

Les sessions lancées par des skills (revues de sécurité) sont masquées des autres vues et des sauvegardes, et regroupées dans une vue Revues de sécurité (en bas de la barre latérale), avec un bouton Nettoyer.
