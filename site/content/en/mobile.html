Phone and remote access

Follow or restart a session from your phone or another computer, get notified when Claude asks a question, and do it without exposing your machine.

On a small screen

The page adapts to small screens: the menu moves into the ☰ button, and Glaude Code installs like an app ("Add to Home Screen").

Open gld to other devices

By default, the page is only reachable from your own computer. To open it from a phone or another computer:

gld --listen 0.0.0.0

Glaude Code then prints an address containing a secret token: open it as is. Without that address, the page asks for the token; it carries the icon and the manifest, so adding it to an iPhone's home screen works from it.

Never expose it directly on the Internet. The connection is not encrypted by default, and the page can read and delete your sessions and launch Claude. Go through a tunnel (SSH, Tailscale…) or serve over HTTPS (below).

Shared machine: set a token

On a machine shared with other accounts, the local address is reachable by them too. Set a token (at least 16 characters): it is required even without --listen, and gld prints the address with $GLD_WEB_TOKEN in place of the token, so that it does not end up in the logs.

GLD_WEB_TOKEN=$(openssl rand -hex 24) gld

gld --token=<token> does the same, but the argument is visible to everyone in ps: prefer the variable.

Connect a phone without retyping the token

  1. On a device that is already connected, open Connect a device (phone icon at the top of the sidebar): it shows an eight-digit code, valid for two minutes and a single use.
  2. On the phone, open Glaude Code (the home-screen app or the browser) and tap Connect this device with a code, under the token or password field.
  3. Type the code: the connection happens where it is typed, so inside the app.

The same code exists as a QR, but the camera then opens the browser, not the app.

  • The phone gets its own session. In token mode, it lasts as long as it comes back at least once every 90 days, can be revoked from the same window and drops if the token changes. With accounts, it is a session of the account that displayed the code, visible in Profile › Sessions.
  • Ten wrong codes per minute block the address for one minute.

Public address

The QR code reuses the address of the page that displays it. If you display it from 127.0.0.1 or the local IP while the phone goes through a domain name (proxy, tunnel), give that public address:

gld --listen 0.0.0.0 --public-url https://gld.example.org   # or GLD_PUBLIC_URL=https://gld.example.org

With a public https:// address on a name (neither an IP nor localhost), gld sends Strict-Transport-Security: max-age=31536000: the browser will then refuse any plain-HTTP access to that name, on any port, for one year. Do not declare as the public address a name that also serves another service over HTTP.

HTTPS with mkcert

On iPhone and iPad, the installed app has no notifications (push included), no native copy and no security key while it is served over HTTP. gld can serve HTTPS itself with a certificate the device trusts, for example one created with mkcert: install its root authority on the iPhone, then enable it in Settings › General › About › Certificate Trust Settings.

mkcert 192.168.0.10 my-pc.local
gld --listen 0.0.0.0 --tls-cert 192.168.0.10+1.pem --tls-key 192.168.0.10+1-key.pem

The GLD_WEB_TLS_CERT and GLD_WEB_TLS_KEY variables are equivalent to the two options. Security keys (WebAuthn) additionally require a domain name, not an IP address.

Push notifications

The 🔔 button at the bottom of the sidebar, to the right of the version, enables for this device a notification when a session asks a question or an authorization request, and when it is waiting for your message. The two types are set separately. They arrive with the app closed.

  • Prerequisites: a page served over HTTPS with a certificate the device trusts, and, on iPhone, the app added to the home screen.
  • Multi-user: each subscriber only receives the sessions of folders where they have the sessions_read right, checked at every send. The subscription follows the session that created it: after sign-out, revocation, expiry or a password change, the device receives nothing anymore; re-enable the button after signing in again. An account has at most 10 subscribed devices.
  • Privacy: the keys and subscriptions are in gld-web-push.json (0600 permissions); only the browsers' push services (Apple, Google, Mozilla, Microsoft) are accepted as destinations.
  • Limits: a secondary configuration folder only sends once its process is launched; an open tab does not silence notifications; the click opens the session in the configuration folder chosen in the browser (for a session from another folder, switch folders first).

Restrict the folder browser

The folder browser (new session, "Reassign", "Move") starts from your home folder and can browse the whole disk. --locations (or GLD_WEB_LOCATIONS) limits it to a comma-separated list of roots, absolute paths or ~:

gld --locations ~/Projets,/mnt/data

The browser opens on the first root and does not go above it. Symbolic links are resolved before the check; a requested path outside the roots falls back to the first one. This bounds the browser, not Claude Code's rights nor the rest of the interface.
