Frequently asked questions

Data, security, backups, costs: short answers, with a pointer to the page that goes into detail.

Do my conversations go anywhere?

No. Glaude Code reads Claude Code's local files (~/.claude). Only the actions that call Claude (writing to a session, rewriting a memory entry, counting tokens) go through your own Claude Code. No claude.ai account is required and nothing passes through a third party.

Can I break my configuration?

Every write is preceded by a backup and a preview of the changes. Deleted memory and rules files go to the trash, from where they can be restored in one click. See Skills, snippets and settings and Memory and rules.

Port 8799 is already in use.

Run GLD_WEB_PORT=8800 gld.

How much does a message sent from the page cost?

Each message reloads the whole context: roughly $1 to $2 on a cold session, far less on a session whose cache is still warm (active within the last hour). Glaude Code announces the cost of a send on a cold session, and the Open sessions view lists the cheapest sessions to resume. See Sessions.

Does it work on Windows?

Yes through WSL2, which is the recommended route. The native Windows binary is compiled but has not yet been tested on a real machine. See Install and get started.

How do I open it from my phone?

Run gld --listen 0.0.0.0, open the printed address, then pair the phone with an eight-digit code. Notifications require HTTPS. Never expose it directly on the Internet. See Phone and remote access.

Can a guest see my other sessions or my files?

No: they only see the shared session, cannot answer permission requests or read configuration files, and absolute paths, your account name and your git identity are masked there. But a session without permission prompts runs its messages directly: only share it with someone you trust. See Share a session.

I restarted my machine, where are my sessions?

Glaude Code records the open sessions every 2 minutes: click Reopen all, or run gld matin --resume. See Sessions.

Can several people use it?

Yes, in multi-user mode: one account per person, a mandatory second factor and nine independent rights per configuration folder. The exec and config_write rights are equivalent to the system account that runs gld.

How do I change the language?

Through the language setting in ~/.claude/settings.json, editable on the Configuration page. See Install and get started.
