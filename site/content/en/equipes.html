Agent teams

Claude Code's native agent teams, driven from the Teams page: a project lead who creates teammates, and you following along, writing and answering their requests from the browser.

Experimental feature. Agent teams are an experimental Claude Code feature, and Glaude Code's handling of them has not yet been verified end to end on a real launch. Try them on a throwaway repository first.

The catalog

Glaude Code ships 21 agents and 11 ready-made teams. An agent has a role identifier (testeur, chef…) and a label ("Tester", "Project lead"), with no first name; a first name is drawn at each launch for every teammate.

"Read" agents only get the reading tools (Read, Grep, Glob); "write" agents get the default tools.

Launch a team

  1. Tick one or more teams: the launched composition is the union of the ticked teams, without duplicates.
  2. Write the goal (4,000 characters at most) and choose the folder.
  3. Click Launch: gld opens the lead's session in tmux, with the list of teammates to create.

Prerequisites: tmux and a terminal launcher (for example terminator, kitty, wezterm, gnome-terminal, konsole, xfce4-terminal or tilix) under the account that runs gld. Without them, the launch is refused, as on native Windows. A launch on a Claude Code version that does not support teams is flagged "unavailable".

The permission mode is Claude Code's default: nothing is approved automatically.

Follow and answer

  • The interface shows each teammate as "First name · Role label"; the lead is "Project lead".
  • Direct messages: write to the lead (default) or to a teammate. The message goes out immediately if the target is idle with no dialog pending; otherwise it is queued (20 at most per team, order preserved).
  • Permission requests: a teammate's requests are displayed in the lead's pane. You answer them from the page; the key is only accepted if a request is actually on screen.
  • The screen shows "Answer in the terminal" when the lead is waiting with no readable request.

To close the team, use the close button: it closes the lead's session and deletes the team's log and queue.

Your own agents and teams

New agent and New team create your own (up to 200 agents and 100 teams). Editing a shipped item creates a personal copy: shipped items are never written. An agent used by a team cannot be deleted.

Limits

  • One team per session; it ends with the lead's session. No nested teams.
  • 3 to 5 teammates are recommended: the interface warns beyond 5, without blocking.
  • Token cost grows with the number of teammates.
  • The message queue is in memory: it is lost when gld restarts.

Rights in multi-user mode

  • sessions_read: see the catalog, the teams and the lead's screen.
  • exec: launch, write, answer requests, close.
  • config_write: create, edit or delete your agents and teams.
