The web cockpit for Claude Code

Find, reread and resume your sessions, drive them from your browser or your phone, share them with a colleague, and stay in control of your memory, rules, skills and settings. Everything stays on your machine: Glaude Code simply reads your ~/.claude folder.

Download View on GitHub

Screenshots show the French interface; Glaude Code also ships in English.

Who is it for?

For you if you use Claude Code every day and:

  • you can no longer find "yesterday's session where we fixed that bug";
  • you have ten terminal tabs open and rebooting the machine scares you;
  • your memory and rules have grown and you no longer know what actually gets loaded, or what it costs in context;
  • you want to follow or restart a session from your phone, or show it to someone;
  • you would rather tick a box than edit settings.json by hand.

What you can do

Find and resume

Sessions grouped by project, search inside conversations, a green dot on running ones, resume in a terminal in one click.

Write without a terminal

Type a message from the page: Claude answers, and you watch live what it does in the tmux session.

Share a session

Single-use invitation link, live follow-along, read-only or write access, revocable, up to 10 guests.

Lose nothing on reboot

Open sessions are recorded every 2 minutes; Reopen all restarts each one in its own tab.

Tidy memory and rules

Token cost per file, broken links, duplicates, contradictions, trash, export and import.

Skills, snippets, settings

Permissions and settings as checkboxes, a preview of each change and a backup before every write.

Workspace

Git file tree, Monaco editor served without a CDN, save, read-only terminal.

On your phone

Installable app, push notifications when a session asks a question or waits for your message (HTTPS required).

Agent teams

A project lead and teammates launched from the page, with a catalog of 21 agents and 11 teams (experimental Claude Code feature).

Several accounts

Password, mandatory second factor and nine independent rights per account and per Claude configuration folder.

Install

A single binary that embeds the interface: no Go, no Node.js, no make. Only Claude Code must already be installed. Pick your system's file from the latest release (Linux, macOS, Windows; amd64 and arm64). On Windows, not yet tested on a real machine, WSL2 is recommended.

  1. Download and verify (Linux amd64 example): 
    curl -LO https://github.com/54tor/glaude-code/releases/latest/download/gld-linux-amd64
curl -LO https://github.com/54tor/glaude-code/releases/latest/download/SHA256SUMS
gh attestation verify gld-linux-amd64 --repo 54tor/glaude-code
sha256sum --ignore-missing -c SHA256SUMS
chmod +x gld-linux-amd64 && mv gld-linux-amd64 ~/.local/bin/gld
  2. Run: 
    gld
  3. Open http://127.0.0.1:8799 in your browser. That's it.

Building from source, Windows (WSL2) and the language setting: install and start. Other devices: phone and remote access. Several people: accounts and multi-user.
