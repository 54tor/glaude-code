Memory and rules

See what Claude actually loads at the start of each session, what it costs, and tidy it up without risking losing anything.

The Memory page

It gathers your CLAUDE.md files, your rules and each project's memory.

  • Read, edit, move, copy a file or an entry.
  • Disable a rule without deleting it.
  • See how many tokens each file adds to every session: that is the context cost paid at each start.

The Health tab

It automatically spots:

  • broken links (an entry pointing to a missing file);
  • indexes that are too long;
  • duplicates;
  • contradictions between entries.

Ask Claude to tidy up

You can ask Claude (Haiku model, a few tenths of a cent) to rewrite or merge entries. The result is a draft that you review before it is written.

Trash: nothing is lost

Any file that is deleted or replaced first goes to a trash, from where it can be restored in one click. Emptying the trash is a separate action.

Export and import

You can export one entry, a selection or all the projects' memory entries to a JSON file, and import it on someone else's setup. The recipient:

  1. chooses the project that receives each group of entries;
  2. ticks the entries to import;
  3. settles each name conflict: skip, replace or keep both.

Rights in multi-user mode

Memory and rules files are instructions: every Claude session in the folder loads them. The mem_write right therefore amounts to being able to steer what other people's sessions do. Details in Accounts and multi-user.
