Skills, snippets and settings

Manage what you usually set by hand in settings.json: through lists and checkboxes, with a preview of each change and a backup before every write.

Configuration

The Configuration page exposes Claude Code's permissions, settings and additional folders.

  • Each change shows what will change before it is written.
  • A backup is made on every write, and can be restored.
  • The language setting on this page also chooses the Glaude Code language.

Skills

  • Read, create, edit a skill and copy it to a project; the list flags poorly described skills.
  • npx skills: skills installed by npx skills are recognized (source, link or copy, update available). You can search, install, update and remove them from the page. Each action shows the exact command before running it; it requires the config_write right.

Snippets

Snippets are your Claude Code /name commands. You can create, edit, import or export them, and insert them into a message.

Account: limits and usage

The Account icon (top right) shows your usage limits and your consumption over the last 14 days.

Dark theme

The interface follows your system's light or dark theme.

Rights in multi-user mode

Writing a hook, an MCP server or a skill runs code under the system account that runs gld: the config_write right is equivalent to that account. Snippets require it too. See Accounts and multi-user.
