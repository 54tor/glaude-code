Le poste de pilotage web de Claude Code

Retrouvez, relisez et reprenez vos sessions, pilotez-les depuis votre navigateur ou votre téléphone, partagez-les avec un collègue, et gardez la main sur votre mémoire, vos règles, vos skills et vos réglages. Tout reste sur votre machine : Glaude Code lit simplement le dossier ~/.claude.

Télécharger Voir sur GitHub

Pour qui ?

Pour vous si vous utilisez Claude Code tous les jours et que :

  • vous ne retrouvez plus « la session d'hier où on avait réglé ce bug » ;
  • vous avez dix onglets de terminal ouverts et redémarrer la machine vous fait peur ;
  • votre mémoire et vos règles ont grossi sans que vous sachiez ce qui est vraiment chargé, ni combien ça coûte en contexte ;
  • vous voulez suivre ou relancer une session depuis votre téléphone, ou la montrer à quelqu'un ;
  • vous préférez cocher une case plutôt que d'éditer settings.json à la main.

Ce que vous pouvez faire

Retrouver et reprendre

Sessions rangées par projet, recherche dans les conversations, point vert sur celles qui tournent, reprise dans un terminal en un clic.

Écrire sans terminal

Tapez un message depuis la page : Claude répond, et vous voyez en direct ce qu'il fait dans la session tmux.

Partager une session

Lien d'invitation à usage unique, suivi en direct, lecture seule ou écriture, révocable, jusqu'à 10 invités.

Ne rien perdre au redémarrage

Les sessions ouvertes sont notées toutes les 2 minutes ; Tout rouvrir les relance chacune dans son onglet.

Ranger mémoire et règles

Tokens coûtés par fichier, liens cassés, doublons, contradictions, corbeille, export et import.

Skills, snippets, réglages

Permissions et réglages en cases à cocher, aperçu du changement et sauvegarde avant chaque écriture.

Espace de travail

Arborescence git, éditeur Monaco servi sans CDN, enregistrement, terminal en lecture seule.

Sur téléphone

Application installable, notifications push quand une session pose une question ou attend votre message (HTTPS requis).

Installation

Un seul binaire qui embarque l'interface : ni Go, ni Node.js, ni make. Seul Claude Code doit déjà être installé. Choisissez le fichier de votre système sur la dernière release (Linux, macOS, Windows ; amd64 et arm64). Sous Windows, encore non testé sur une vraie machine, WSL2 est recommandé.

  1. Télécharger et vérifier (exemple Linux amd64) : 
    curl -LO https://github.com/54tor/glaude-code/releases/latest/download/gld-linux-amd64
curl -LO https://github.com/54tor/glaude-code/releases/latest/download/SHA256SUMS
gh attestation verify gld-linux-amd64 --repo 54tor/glaude-code
sha256sum --ignore-missing -c SHA256SUMS
chmod +x gld-linux-amd64 && mv gld-linux-amd64 ~/.local/bin/gld
  2. Lancer : 
    gld
  3. Ouvrir http://127.0.0.1:8799 dans le navigateur. C'est tout.

Compiler depuis les sources, Windows (WSL2), accès depuis un autre appareil, multi-utilisateur : voir le README.
